Hello and welcome to this new website! This is my first post using this entire Jekyll thing; so it's kind of a stretch to see what other features I add while I write this thing.<br><br>

You may be wondering why this website looks alot different to the past; or may be curious as to why this website is somehow new? e.g. what was the old one and what not. 
## the previous website
The previous website (which you can still find on [an old branch](https://github.com/Terran-is-Here/Terran-is-Here.github.io/tree/main-v2)) was hosted on the same service as this one is (github pages :3). It was however entirely coded out of pure HTML, CSS and JS; meaning that if I had to make a change to the layout and theming (e.g. tags), I would have to update it across all instances of the website with the same theme.
<br><br>
Updating it in this state was a terrible pain in the ass. I had to do more coding than writing for alot of things, and it wasn't really that maintainable. You may be saying; why didn't I use a static site generator or some kind of tool to make the workflow easier? Simple: I was stupid and just didn't know of them at the time.
<br><br>

Additionally, I had made a small set of choices that also made expanding on it further incredibly painful; since I would need to update all of the links and whatnot. ~~the website would also decimate it's own data rate in my experience but i digress~~

## the new website
This new website on the other hand is finally; finally built atop of Jekyll. This means that I can spend alot more of my time writing things in terms of .md files instead of manually coding *and* writing pages.

<br>Setting up all the backend for this was quite a learning curve; although it was really fun and reminded me of a previous project I had to set up a personal sandbox wikidot page back when I was trying to write for the Backrooms Wikidot ~which we will not discuss~ <br><br>

The current theme of this website, atleast when I wrote this page, is roughly based off a basic computer gui for the main contents of the page. I still haven't figured out what I really want to do for the header, but I'll keep it like that for now. 

<br> It really is just a conglomeration of things that I find cool and whatnot to chuck into the site. Expect things to change as I think through and realize that alot of these things look stupid.

## roadmap ahead
Currently on the list of major improvements is to make this site properly responsive to mobile devices. It currently really isn't, and I've been procrastinating on doing it since it's genuinely terrible to work on making sites responsive. 

<br>I also want to add more themes and simplify the backend of things in terms of holy hell it's terrible back there; as well as some little formatting tidbits. This article is really just a test as well as a proof of concept as to how things look; and future ones will be more enjoyable to read. hopefully
